# CONTRIBUTING

## New Cards
**DO NOT** submit pull requests adding new default card objects unless they are cards from the original UNO game.

However, creative new cards added as advanced card objects in `extended_advanced_card_objects_with_desc` are welcome.

## Features
Pull requests adding new features are welcome.

New features should preferably be part of the [Road Map](./ROAD_MAP.md) and follow the project's [Architecture](./ARCHITECTURE.md).

## Bug Fixes & Documentation
Pull requests fixing bugs or adding documentation are welcome.

## Refactoring
Please discuss your proposed refactoring in GitHub Issues before submitting a pull request.

## Assets
Please compress assets before submitting a pull request. Whenever possible, prefer SVGs for icons and other vector graphics to help reduce file sizes.

I used [VectorFree](https://github.com/zavants/VectorFree) for converting png into SVG. Open source and very easy to use.
